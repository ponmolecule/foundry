Component tools stay available. Workforce defaults and assessments remain in their own subtab. Long explanations and the workforce run audit are collapsed rather than deleted.

## Calculated values and provenance

The table and selected workforce footer read each population's calculated expense from a new diagnostic population_comp output. The runtime records the expense it already computes, including resolved activation, Count/basis, amount period, payroll load and end period. Profile A publishes the final runtime values; Profile B uses the existing WorkforceRuntime for the diagnostic only. Public conversion scales these monetary arrays to $000s. Saved configuration schema and economic rules are unchanged.

The UI labels these values as the latest engine run and shows Awaiting run when a population has no matching result. Source schedule previews are authored amounts, not calculated payroll. They are not substituted for engine results.
