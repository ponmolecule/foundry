# r201IQ — original navigation and whole-platform Klaros theme

All pre-IQ r198 top-level menu definitions, labels and ordering are restored verbatim. Every tab is visible at the top, with wrapping on smaller screens. The More menu is removed. The original embedded Klaros logo is restored in the application ribbon and Welcome screen.

The supplied Klaros reference governs the palette: charcoal, neutral gray, white and restrained gold. Presentation colors are applied across the application, including Welcome, product configuration, financial statements, executive summaries, books and advanced panels. System sans-serif typography replaces the IQ serif headings. The Configuration workspace uses compact fields, proportional widths, aligned labels, visible schedule previews and advanced-setting summaries. Existing actions, original section names and controls are retained.

The same live assumptions and curve nodes mount inside Configuration and return to the original sidebar on other tabs. They are not duplicated. This release changes presentation only; no engine files are changed.
