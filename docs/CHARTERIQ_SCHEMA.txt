⚠️ TYPE GOTCHAS — read before writing any query
  1.    active is INTEGER (0/1), NOT boolean. WHERE active = TRUE fails (this caused a
        502). Use WHERE active = 1 . Applies to institutions.active , flags.active .
  2.    institutions.state is a 2-letter USPS code ('TX', 'CA' — never 'Texas'). Normalised
        2026-07-21; uniformly 2-letter now. ( ffiec_por.state is separate, varchar(4) .)
  3.    call_report_items.value_num is in USD THOUSANDS (usd_k). A value of
        1,328,610,000 means $1.328 trillion. Check the unit column; ratio items carry a literal
        '%' and live in value_text .
  4.    metrics.value and peer_percentiles percentiles are already scaled to the metric's
     natural unit (ratios in percent, e.g. roa 1.43 = 1.43%). Do not re-scale.
  5. Time is (year, quarter) integer columns, not a date. Latest = year*10+quarter max,
     or (year, quarter) tuple compare. A period string like '2026Q1' is display-only, not a
     column.
  6. No per-quarter total assets in institutions . institutions.asset_size_mm is a
     STATIC present-day value repeated conceptually; for historical size use the semantic
     view's total_assets_mm (from item 2170) or compute from call_report_items .
  7. Survivor bias: for questions about a PAST quarter, do NOT filter institutions.active
     = 1 — that drops banks that existed then and have since exited. Filter active only for
     present-day questions.

Asset quality — charge-off (M5, current, NEW 2026-07-21):
     net_charge_off_rate — DEFAULT. Net CO (gross − recoveries), UBPR one-quarter
     annualized, over PERIOD-END total loans (RC-C 2122). Matches FDIC public / Klarify.
     Higher = worse; can go slightly negative when recoveries exceed charge-offs (best).
     net_charge_off_rate_ubpr — UBPR examiner convention, over AVERAGE loans (RC-
     K 3360). Slightly higher than the default for a growing book.
     gross_charge_off_rate, gross_charge_off_rate_ubpr.
     Dollar aggregates (no percentile bands): net_charge_offs_dollars, charge_offs_dollars,
     recoveries_dollars, provision_dollars.
     Both rates ANNUALIZED — annualize a modeled quarterly flow (×4) before placing
     against the band.

Canonical join recipes
 sql

 -- A metric with its peer band, latest quarter, for one bank + one cohort:
 SELECT m.value, p.peer_p10, p.peer_p50, p.peer_p90, p.peer_count,
        p.percentile_rank
 FROM metrics m
 JOIN peer_percentiles p USING (cert, year, quarter, metric_name)
 WHERE m.cert = :cert AND m.metric_name = 'net_charge_off_rate'
   AND p.group_type = 'asset_band' AND p.group_id = :band
   AND m.year = 2026 AND m.quarter = 1;

 -- Present-day active banks only (gotcha 1 & 7):
 SELECT * FROM institutions WHERE active = 1;   -- NOT active = TRUE

 -- Raw item -> bank:
 SELECT c.mdrm_code, c.value_num, i.name
 FROM call_report_items c
 JOIN ffiec_por f ON f.idrssd = c.idrssd AND f.report_date = c.report_date
 JOIN institutions i ON i.cert = f.fdic_cert
 WHERE c.report_date = '2026-03-31' AND c.mdrm_code = 'RIAD4635';
