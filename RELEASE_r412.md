# r412 — Cash-linked securities targets and quarterly timing

Managed portfolios now reuse stable prior-period sources for total bank cash and enabled named cash allocations. The named cash source uses the component's finalized ending history and explicit opening, not its independent income balance basis. Current-period cash targets are rejected to prevent circular funding. Source selection initializes prior-period timing and Opening source; missing/deleted/incompatible sources fail validation.

Target sampling can remain Every model period (legacy) or use engagement quarters (M1, M4, …). Quarterly sampling freezes the beginning source, target ratio and sleeve allocations for the quarter. A selected Ramp from prior quarter end interpolates each sleeve from its previous quarter-end holdings to the authored target; Hold target remains available. Native quarterly models reach the target in one step. This is model-quarter timing anchored to forecast M1, not calendar-quarter scheduling. Quarterly sampling is supported for monthly/quarterly models only and requires prior-period sources.

Interest can use Ending holdings (legacy) or Average beginning and ending holdings. With a linear monthly ramp and constant yield within each quarter, summed monthly interest equals the quarterly average-balance calculation. Varying intraquarter yields need not match an independently authored quarterly yield. Net sales remain signed and maturities/purchases continue through the existing book/funding engine. No independent income entry, duplicated asset, fixed instrument name, percentage, or engagement-specific logic is introduced.

The target source gets full available row width; timing, opening initialization and ratio stay grouped below it. Source commentary and sleeve interest explanation follow the selected method. Existing saved contracts retain native-period targeting and ending-balance interest unless changed. Save mechanism unchanged.

Validation: new tests cover source Q1 target $89,517,527.40 and interest $979,644.5674; two-quarter monthly/quarterly equivalence, source sampling, signed sales, solver purity, missing source/timing rejection, named cash full-engine securities balances and income posting. Browser checks run the real Configuration renderer and current Securities layout, including source selection, timing, target path, interest settings and source bounds at 1440/1024/768. Syntax, cash income and balance-formula regressions pass.
