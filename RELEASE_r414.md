# r414 — Balance Sheet display cadence

The Balance Sheet now has the same Monthly / Quarterly / Annual selector as the Income Statement, restricted to the engagement's native cadence and coarser choices. This is session-only display state, independent of the Income Statement selection. It is never written into assumptions or saved engagements.

Unlike flow totals on the Income Statement, stock rows select the final native observation of each display period: M3/M6/M9/M12 for quarterly and M12/M24/etc. for annual views; Q4/Q8/etc. for annual views of quarterly models. Opening balances remain a separate column. Incomplete final groups are labelled partial and use their last modeled date; missing end observations remain blank rather than silently using an earlier balance or zero. Every primary Balance Sheet row and memo table uses the same selection. There is no summed Total column. Section widths match the selected number of periods, and cell provenance refers to the corresponding original native observation. The existing supplemental year-end summary remains unchanged.

Implementation reuses the Income Statement's group definition and toolbar styling, with a stock-specific value/row/header presentation. No financial engine, assumptions, data schema, save endpoint, export calculation, or underlying result arrays changed.

Validation: real-tab browser checks cover native monthly display, quarterly/yearly snapshots, separate opening values, partial groups, assets/liabilities/prepaid/accrued balances and off-balance-sheet memos, end-period provenance, independent Income Statement selection, quarterly/yearly native fallbacks, missing/short arrays, no summed total, and mobile control bounds. Switching views invokes neither the engine nor autosave, leaves complete configuration/result JSON unchanged, and retains CLEAN lifecycle state. Existing Income Statement browser regression passes its sum/memo/partial/opening/no-mutation checks. All inline/generated JavaScript syntax and balance-formula controls pass. Desktop/mobile views inspected.
