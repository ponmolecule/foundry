# r457 — Cumulative gross acquisition count source

Adds a stable, reusable Account activity level for each eligible Customer acquisition feed: Cumulative gross acquisitions. It is the running sum of the canonical monthly gross new-customer additions from M1, excluding opening customers and without deducting attrition. This uses each feed's actual allocated additions, including its authored rounding policy. It does not duplicate acquisition equations or alter active customer books.

Driver source Customer acquisition / account activity exposes the count to Account streams. Activity source lists each feed's cumulative gross acquisition count. Month-end and average-count measures retain the existing monthly-first fee/cost calculation; quarterly counts are not summed as flows. A 45-dollar annual per-account cost uses each month's count divided by 12, then sums monthly expenses in quarterly models. Pricing remains independent from costs.

Source IDs derive from the feed's persisted customer-count ID, so renaming a feed preserves links. Sources are discovered without adding saved metadata; the result count is computed and published only when referenced. Straight-line interpolated stock feeds are excluded because their net changes do not establish gross acquisitions. No migration, automatic selection, client-specific computation or financial default changes.
